                Trust and how far to rely on skills

                What a skill can do

                A skill is instructions an agent reads and follows. A skill may tell the agent to run commands, edit files, or run the scripts it carries; the agent does that with the permissions you gave it. A card says "holds N scripts" when a skill carries code an agent may run.

                What formskills checks

                • It reads only the Form family's own releases, listed in the family catalogue, which must carry a signature from a key built into formskills; an unsigned or wrongly signed catalogue is refused.
                • Each skills download must match the catalogue's SHA-256, and unpacking refuses links, paths that leave the folder, and oversized archives.
                • formskills shows skills as text and never runs them. The format check reads the files; it does not judge what they ask an agent to do.

                A signature says where a skill came from and that it was not changed on the way. It does not say the skill is right for your task or safe on your computer.

                Sources that are not releases

                Dev mode reads app checkouts on this computer: unreleased work, not signed and not checked. A kept copy is the last release formskills checked, shown when the catalogue cannot be read now. Your own skills and edited copies are yours; formskills keeps them but did not write their instructions.

                How far to rely on them

                Skills are provided as they are, under each app's licence, without warranty. They describe how the Form apps work at their release and can be wrong, out of date or incomplete. Read a skill before you give it to an agent, keep the agent's own approvals on, and check what it changes. Pin an app to an earlier release when a newer skill does not suit you.

                The skill format

                A skill is a folder holding a SKILL.md file and any files it points to. The Form apps follow the open Agent Skills format, which Claude Code, Codex and Cursor read.

                The folder

                skill-name/
  SKILL.md                    the card: front matter, then instructions
  sub-skills/x/SUB-SKILL.md   the family's routed parts (optional)
  references/                 documents read when needed (optional)
  scripts/                    code the agent can run (optional)
  assets/                     templates and data (optional)

                SKILL.md

                It opens with front matter between two lines of three hyphens, then Markdown instructions.

                ---
name: pdf-tools
description: Fills, merges and redacts PDFs. Use when the person works with PDF files.
license: GPL-3.0-only
---
                FieldNeededRules
                nameRequired1 to 64 characters: lowercase letters, digits and hyphens; no hyphen at either end or two in a row; the same as the folder's name. Claude also refuses XML tags and the words "anthropic" and "claude".
                descriptionRequired1 to 1024 characters saying what the skill does and when to use it; no XML tags. Agents choose skills by it.
                licenseOptionalA licence name, or a licence file in the skill.
                compatibilityOptional1 to 500 characters on what the skill needs: a product, packages, network access.
                metadataOptionalExtra keys and values for other tools.
                allowed-toolsOptionalTools the skill may use without asking; experimental, not read by every agent.

                How agents read it

                Every skill's name and description is read when the agent starts; the rest of SKILL.md when the skill is used; other files only when the instructions call for them. Keep SKILL.md under 500 lines and link other files by paths relative to the file that links them, inside the skill.

                What Check reports

                An error breaks a rule above, so an agent may refuse or misread the skill. A note is advice: a long SKILL.md, or a link to a file the skill does not hold. Check runs on every released skill and on your copies while you edit.

                Sources: the Agent Skills specification (agentskills.io/specification) and Claude's Agent Skills overview (platform.claude.com).
